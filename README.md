# neovim-12-dotfiles

Brand new configuration dotfiles for Neovim 0.12

## Why

I have a full configuration that I have maintained over the years. It includes
my own customizations, but also it leverages heavily plugin manager system along
with many plugins from the community.

Now that Neovim 0.12 shipped, it includes native functionality for color themes,
plugin management, LSP, autocomplete, etc. I'm going to try a brand new
configuration with those native systems...

Thus this repo ...
